# Build resources

electron-builder picks up icon assets from this folder by convention.

## Files in this folder

| File | Purpose | Status |
|---|---|---|
| `source.svg` | Source-of-truth artwork. Hand-edit this, then render the rest. | Committed |
| `icon.png` | 1024x1024 PNG. electron-builder uses this on Linux directly and falls back to it on Mac/Windows when `icon.icns` and `icon.ico` are missing. | Generated by `npm run gen:icons` |
| `icon.icns` | macOS multi-resolution icon (16, 32, 64, 128, 256, 512, 1024). | Not committed. electron-builder auto-derives from `icon.png`. |
| `icon.ico` | Windows multi-resolution icon (16, 24, 32, 48, 64, 128, 256). | Not committed. electron-builder auto-derives from `icon.png`. |

## Where the icon is consumed at runtime

`gen:icons` writes the same PNG to two locations:

1. `build/icon.png` (this folder).
   - Bundled into packaged builds via `package.json#build.files`.
   - Read by `src/main/index.ts` through `app.getAppPath()` and passed
     to `BrowserWindow({ icon })`. That controls the taskbar icon on
     Windows and Linux and the Dock icon on macOS (in dev mode).
   - electron-builder also derives the platform-specific `.icns` and
     `.ico` from this PNG when packaging.

2. `src/renderer/public/icon.png` (Vite-served renderer asset).
   - Served at `/icon.png` in both dev and production renderer bundles.
   - Referenced by `src/renderer/index.html` via
     `<link rel="icon" href="/icon.png" />`. That controls the window
     title-bar icon and any browser-style favicon UI.

If you edit `source.svg`, run `npm run gen:icons` and commit the
regenerated PNGs in both locations. Other contributors should not need
`sharp` to build.

For the first release the auto-derived `.icns` and `.ico` are
acceptable. Shipping native multi-resolution files renders sharper at
small sizes (the macOS Dock at 16px is the obvious place), but it isn't
blocking.

## Regenerating `icon.png`

The generator script is [`scripts/build-icons.mjs`](../scripts/build-icons.mjs).
It uses `sharp` to render `source.svg` to `icon.png` at 1024x1024.

```bash
npm i -D sharp     # one-time, on whichever machine renders icons
npm run gen:icons
```

`sharp` is in `devDependencies` so `npm install` is the only setup
needed before running `gen:icons`. If the native prebuild is missing
for your platform, `npm rebuild sharp` usually fixes it.

## Generating native `icon.icns` and `icon.ico` (optional)

For sharper small-size rendering, generate the platform-specific
multi-resolution files. Easiest path (run on macOS):

```bash
mkdir icon.iconset
for size in 16 32 64 128 256 512 1024; do
  sips -z $size $size icon.png --out icon.iconset/icon_${size}x${size}.png
done
iconutil -c icns icon.iconset -o icon.icns
rm -rf icon.iconset
```

For Windows `.ico` (cross-platform via ImageMagick):

```bash
magick icon.png -define icon:auto-resize=256,128,64,48,32,24,16 icon.ico
```

Commit the generated `.icns` and `.ico` next to `icon.png` so releases
are reproducible without ImageMagick on every machine.
